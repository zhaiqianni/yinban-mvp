# 淘宝采购清单

## 首选采购方式

搜索：

    ESP32 WROOM 智能小车套件 五路循迹 超声波避障 蓝牙 已焊接

优先选包含 ESP32-WROOM-32、两轮底盘、TB6612FNG、五路巡线、宽电压超声波、电池方案和完整教程的套件。不要因为页面写了“ESP32”就直接下单。

## 下单前向卖家确认

1. 主控是否为 ESP32-WROOM-32，而不是 C3、S2 或 S3。
2. 是否支持经典蓝牙 SPP，并可在 Windows 中形成虚拟 COM 口。
3. 电机线、排针和电源开关是否已经焊好。
4. 巡线模块输出是否适配 ESP32 的 3.3V IO。
5. 超声波是否为 HC-SR04P 或其他明确支持 3.3V 的型号。
6. 是否提供原理图、接线图、Arduino IDE 例程和所需库。
7. 电池、充电器、开关、螺丝和铜柱是否包含。
8. 能否在开发第三天前到货。
