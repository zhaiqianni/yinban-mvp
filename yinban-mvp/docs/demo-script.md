# 两分钟现场演示脚本

## 演示前

- 打开 http://127.0.0.1:8000。
- 确认页面右上角显示真实硬件模式；否则说明正在使用模拟模式。
- 把小车放在起点，确认轮子和线材不被卡住。
- 清空路线上的障碍物。
- 准备一个轻质纸盒作为障碍物。
- 在桌面保留备用演示视频。

## 正式演示

讲解者：

“很多老年人在医院遇到的困难，不只是找不到路，还包括不会使用自助机、不理解下一步流程，以及在陌生环境中的焦虑。银伴把问询、流程辅助、导引和求助放到一个入口里。”

操作员说：

“我要去心内科。”

系统回答后，讲解者：

“系统识别目的地，调用本地医院知识库，并给出大厅、3号电梯口和心内科的路线。固定问题不依赖网络或大模型。”

点击“开始导引”，小车出发。

在小车前放置纸盒：

“超声波检测到前方障碍后，小车立即停车，页面同步显示受阻状态。”

移除纸盒，等待小车继续并到达：

“当前版本是面向比赛的固定环境概念验证。真实部署还需要 SLAM、动态避障、电梯和医院系统接口，这些属于后续迭代，不是本原型已经实现的能力。”

## 故障降级

- 语音失败：立即点击“去心内科”。
- 蓝牙失败：切换 USB 或模拟模式。
- 小车失败：继续展示路线动画，并播放备用视频。
- 页面失败：重启 run.ps1，不在现场安装或升级依赖。
