- 重连后的停止指令发送成功。

### 第二轮

### 第三轮

- 重新上电后自动恢复为 `connected=true / IDLE`，网页恢复显示“等待任务”。
- 最终动力测试中，开始和停止指令均被真实硬件接受；小车车轮先转动，约一秒后停止，用户现场确认行为正确。

## 验收结论

本次修复通过全部验收条件：小车断电不会拖死网页后端，网页能区分机器人离线和后端离线，COM6 恢复后能够自动重连，离线控制指令不会误报成功，重连后的开始与停止控制可正常执行。比赛用 `start-yinban.cmd` 已固定为 COM6 真实硬件模式，后续正常使用无需手动设置环境变量。

应用层无法替代 Windows 修复被永久删除的蓝牙配对或驱动。如果设备管理器不再提供 COM6，需要重新配对设备，或在启动脚本中更新 Windows 新分配的发送端口号。
