# ESP32 小车接线说明

以下引脚对应 firmware/yinban_car/yinban_car.ino 的默认配置。实际套件如使用专用扩展板，应以卖家原理图为准，并同步修改固件顶部的引脚常量。

## 默认引脚

| 模块 | 信号 | ESP32 GPIO |
|---|---|---:|
| TB6612FNG | STBY | 23 |
| TB6612FNG | PWMA | 25 |
| TB6612FNG | AIN1 | 26 |
| TB6612FNG | AIN2 | 27 |
| TB6612FNG | PWMB | 14 |
| TB6612FNG | BIN1 | 16 |
| TB6612FNG | BIN2 | 17 |
| 五路巡线 | S0–S4 | 32、33、34、35、39 |
| HC-SR04P | TRIG | 18 |
| HC-SR04P | ECHO | 19 |
| 自复位按钮 | SIGNAL | 13 |

GPIO 34、35 和 39 只能作为输入，适合巡线传感器，但不能用于电机或触发输出。

## 上电前检查

1. 关闭小车电源并断开电池。
2. 检查正负极、TB6612FNG 的 VM/VCC/GND 和电机输出。
3. ESP32、传感器和电机驱动必须共地。
4. 不要把普通 HC-SR04 的 5V Echo 直接接到 ESP32。
5. 用万用表确认巡线模块高电平不超过 ESP32 允许范围。
6. 抬起车轮，先空载测试左右轮方向。
7. 确认 STOP 后两侧电机都断驱动，再把车放到地面。

## 方向调整

如果前进时某一侧轮子反转，不要交换电源正负极。优先：

- 交换该电机接在 TB6612FNG 输出端的两根线；或
- 修改固件中的 LEFT_MOTOR_REVERSED / RIGHT_MOTOR_REVERSED。

## 巡线传感器

- 黑线宽度建议 18–25 mm。
- 传感器离地通常保持约 5–12 mm，按模块实际效果调整。
- 先低速测试直线，再测试半径较大的弯道。
- 如果黑白逻辑相反，修改 LINE_ACTIVE_LOW。

## 供电

优先采用套件卖家给出的配套供电方案。不要把电机直接接 ESP32 的 3.3V 或 5V 引脚。发现芯片过热、异味、线材发软或电池鼓包时立即断电。
