# 故障排查

## 页面打不开

确认 PowerShell 中服务没有退出，然后打开：

    http://127.0.0.1:8000/api/health

如果健康检查失败，重新运行：

    .\run.ps1

## 中文语音按钮不可用

- 使用最新版 Edge 或 Chrome。
- 语音权限需要在用户点击按钮后授予。
- 现场噪声大时直接使用大按钮或文字输入。
- 语音识别不是 P0 的唯一入口，不要在现场反复调浏览器权限。

## 页面显示模拟模式

- 确认 ESP32 已配对或通过 USB 连接。
- 在设备管理器中确认实际 COM 口。
- 启动前设置 YINBAN_MODE 和 YINBAN_ROBOT_PORT。
- 关闭占用该 COM 口的 Arduino 串口监视器。

## 蓝牙无法形成 COM 口

- 确认主控是 ESP32-WROOM-32。
- 确认固件已经成功运行 SerialBT.begin。
- 删除旧配对后重新配对。
- 比赛前固定使用已经验证的电脑，不临时更换。
- 无法恢复时使用 USB 或模拟模式。

## 小车方向相反

抬起车轮后测试。交换对应电机的两根输出线，或修改固件的电机反转常量。

## 小车左右摆动

- 降低 BASE_SPEED。
- 降低 KP。
- 增加少量 KD。
- 调整传感器离地高度。
- 清理胶带反光、接缝和急弯。

## 小车经常丢线

- 增加黑线宽度。
- 放大弯道半径。
- 重新调整五路传感器电位器。
- 检查杜邦线是否松动。
- 先只保留直线加缓弯的一条路线。

## 超声波错误停车

- 确保传感器正对前方且没有被车壳遮挡。
- 检查供电和共地。
- 将障碍阈值从 20 cm 小幅降低。
- 保留连续多次读数确认，不要用一次测距直接停车。

## ESP32 反复重启

- 立即断电并检查短路。
- 电机不能由 ESP32 供电引脚直接驱动。
- 检查电池电压、TB6612FNG 供电和共地。
- 固定松动线材，避免电机启动时接触不良。
