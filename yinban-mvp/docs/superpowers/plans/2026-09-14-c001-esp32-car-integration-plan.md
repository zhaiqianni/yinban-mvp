# C-001 ESP32 小车接入实施计划

对应设计：`../specs/2026-09-14-c001-esp32-car-integration-design.md`

## 任务一：建立可重复的 ESP32 构建环境

- 安装 Arduino CLI。
- 安装并锁定 Espressif ESP32 开发板支持包。
- 记录板型、端口和编译/上传命令。
- 验证 `COM5` 仍对应 CH340 小车主控。

## 任务二：传感器只读诊断

- 新建独立诊断程序，不调用任何电机驱动函数。
- 每 250 毫秒输出左右循迹原始值和超声波距离。
- 编译并烧录到 `COM5`。
- 在白底与黑线条件下记录 GPIO 36、39 的实际电平。

## 任务三：电机安全诊断

- 新建短脉冲、低速度电机测试模式。
- 默认上电停车，只有收到串口确认命令才驱动。
- 架空车轮后分别验证左右轮的正转、反转和停止。
- 将方向修正收敛为配置常量。

## 任务四：适配正式固件

- 将电机引脚改为 16、17、26、27 的直接双 PWM 驱动。
- 将五路循迹改为 GPIO 36、39 的双路状态机。
- 将超声波改为 Trig 32、Echo 33。
- 保留 USB/蓝牙共用的命令协议和安全停车逻辑。
- 加入宽黑条持续确认、起步保护和单次到达事件。

## 任务五：软件与自动化验证

- 为纯逻辑状态转换、终点去抖和命令解析补充主机端测试。
- 编译诊断程序和正式固件。
- 运行现有 Python 测试，确认网页功能没有回归。
- 更新接线、烧录、蓝牙配对和场地铺线文档。

## 任务六：实车与网页联调

- 短直线校准循迹模块高度和电位器。
- 低速验证大圆弧、宽黑条终点和障碍停车。
- USB `COM5` 联调成功后切换到蓝牙虚拟 COM 端口。
- 连续完成 10 次演示并记录成功次数与故障原因。
